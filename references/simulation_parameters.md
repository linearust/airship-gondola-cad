# 비행선 시뮬레이션 입력 — BJ CAD 기준

**실제 CAD의 추진기 간격은 150 mm, 레일 접촉면부터 회전축까지는 50 mm입니다.**
별도의 반올림 값 없이 이 설계값을 사용합니다. 정밀한 system identification에는
제작·설치 후 실측값을 우선하고, 실측 전에는 CAD 값을 사용합니다.

[SI 단위 파라미터 파일](simulation_parameters.json)은 검증된 저장 CAD에서 읽은 스냅샷입니다.
`exact_geometry`는 CAD 값이며, `whole_airship`의 `null`은 미확정값입니다.
**미확정값을 0으로 대체하지 않습니다.**
파일의 CAD·소스·검증 보고서·추출기 해시로 적용 대상을 구분합니다.

## 1. 계산에 필요한 주요 길이

| 항목 | CAD 값 |
| --- | ---: |
| 두 주추진기 회전축 중심 사이 | **150 mm** |
| 추진기 쌍의 중심에서 각 축까지 | **75 mm** |
| 레일의 기낭 접촉면 Z=0부터 회전축까지 | **50 mm** |
| 레일 접촉면부터 광학센서 피치축까지 | **35 mm** |
| 주프로펠러 지름 | 40 mm |
| 레일 길이 | 340 mm |
| 서보각→출력축 각도 | −3배 |

기어 중심거리 16 mm, 베어링·샤프트·혼·체결부 치수는 임의로 반올림하지 않습니다.

배터리/FC/항법 마운트의 레일 방향 기준 위치는 각각 **+90 / −54 / −158 mm**입니다.
광학센서는 배터리 캐리어의 +X 슬롯에 붙으며 피치축의 기본 X 위치는 **+117 mm**입니다.
이 값은 레일 지지·배선·간섭 조건과 연결되므로 그대로 기록합니다.
마운트 기준점은 무게중심이 아니며, 실제 균형 조절 후 위치를 갱신해야 합니다.

## 2. 좌표와 추력 작용점

현재 CAD 원점 O는 **펴진 레일의 길이·폭 중앙, 기낭 접촉면 Z=0**입니다.
기낭 전체의 부피중심 **CV**도, 곤돌라의 무게중심도 아닙니다.
기낭에 붙여 휜 레일과 설치 각도는 이 곧은 CAD에 반영되지 않았습니다.

- CAD +X: 레일 길이 방향, 중립 상태 모터의 기하학적 축 방향.
- CAD +Y: 객체 이름이 `Port`인 쪽. `Starboard`는 −Y 쪽입니다.
- CAD +Z: 기낭에서 멀어지는 방향, 명목상 아래쪽.

**CAD의 이름을 그대로 기체 전방·우측·하방(FRD)에 대응시키지 않습니다.**
실제 전방과 좌우를 확인해 올바른 회전행렬 R을 정합니다.
한 축의 부호만 뒤집는 것은 회전이 아니라 반사이므로 토크·각도 변환에 쓰지 않습니다.

중립 상태의 모터 몸체 중심은 회전축 중심과 일치합니다.

| CAD 객체 | O→회전축 좌표 [mm] | 추진기 기준점 P→회전축 [m] |
| --- | --- | --- |
| Port | (0, +75.1, 50) | **(0, +0.075, 0.050)** |
| Starboard | (0, −74.9, 50) | **(0, −0.075, 0.050)** |

두 열 모두 정확한 설계 좌표이며, 원점만 다릅니다. 추진기 기준점 **P**는
실제 두 축의 중점을 레일 접촉면 Z=0에 투영한 점입니다. 현재 O→P는
**(0, +0.0001, 0) m**로, 공통 Y=+0.1 mm의 레일 클램프 좌면 이동을 포함합니다.
P의 좌표축은 CAD와 같으며 `r_motor_CAD = r_O→P + r_P→motor`입니다.
클램프 방향이나 레일 위치를 바꾸면 P의 CAD 좌표도 함께 갱신합니다.
P는 CV나 CG가 아니며, 이 원점 이동은 반올림이나 오차 생략이 아닙니다.

네이티브 +Y축 기준 틸트각 θ를 쓰면 모터의 기하학적 축은 다음과 같습니다.
θ는 rad이며, 각 모터의 중립·방향·끝점과 실제 추력 부호는 시험으로 정합니다.

```text
u_CAD(θ) = (cos θ, 0, −sin θ)
F_vehicle = T × R × u_CAD(θ)       # T는 부호 있는 실제 축방향 추력
r_motor_vehicle = r_CV→O + R × r_motor_CAD
τ_CV = r_motor_vehicle × F_vehicle
τ_CG = (r_motor_vehicle − r_CV→CG) × F_vehicle
```

프로펠러 원판 외형의 중심은 회전축에서 모터축 방향으로 12 mm 떨어져 있습니다.
축방향 추력만 모델링하면 이 차이는 힘과 평행하므로 모멘트가 같아,
**고정된 회전축 중심을 추력 작용점으로 사용**할 수 있습니다.
측력·프로펠러 반작용 토크·회전부 질량분포까지 같다는 뜻은 아닙니다.

광학센서는 기존 범용 캐리어에 체결하며 피치 한 축을 수동 조절합니다.
현재 피치 0°에서 피치축은 **(117, −0.1, 35) mm**,
`MTF-02P` 외형 중심은 **(117, −0.1, 45.75) mm**입니다.
예시 계류 전원 구성에서는 같은 받침을 항법장비 캐리어의 −X 슬롯으로 옮기며,
그 피치축은 **(−131, −0.1, 35) mm**입니다. 배치 변경 후 좌표를 다시 추출합니다.
외형 중심은 렌즈 원점이 아닙니다. FC 외형 중심 역시 IMU 위치가 아닙니다.
센서 관측모델에는 실제 센서 원점·방향을 별도로 확인합니다.

## 3. 팀에 전달할 전체 기체 입력

CV는 우선 **팽창한 기낭의 배제체적 중심**으로 정의하는 것을 제안합니다.
타원체 근사에서는 타원체 중심입니다. 아래 값은 아직 확정되지 않았습니다.

| 요청값 | 필요한 측정·선택 |
| --- | --- |
| 헬륨 포함 전체 질량 [kg] | 기낭·밸브·곤돌라·배터리·배선·안테나·테이프 등 실제 탑재 건조질량 + 내부 혼합기체 질량 |
| 관성 대각값 Ixx/Iyy/Izz [kg·m²] | **전체 CG 기준**, 선택한 기체 좌표축. 구성품별 질량·CG 위치와 기낭 형상/질량 필요 |
| CV→CG [m] | 같은 좌표계의 질량별 위치 또는 별도 균형 측정 |
| CV→각 모터 [m] | 위 주모터 좌표에 실제 O의 장착 위치·회전 적용. **후방 yaw 모터는 CAD 범위 밖이므로 별도 측정** |
| 기낭 타원체 크기 [m] | 실제 팽창 상태의 전체 길이 L·폭 W·높이 H와 장축 방향. ‘2 m급’만으로 확정 불가 |
| 내부 기체 순도 | 기낭 내부 헬륨 몰분율/이상기체 체적분율. 충전용 실린더의 표시 순도와 구분 |
| CV→곤돌라 [m] | 장착 기준점 O인지 **곤돌라 CG**인지 구분. 두 벡터를 별도 기록 |

CAD 질량 예산은 밀도·기성품 질량 가정에 따른 부분 합계입니다.
배터리·배선·접착재·기낭·가스·일부 체결품 등과 불명 질량이 누락되어,
총질량이나 최소 보장 질량으로 쓸 수 없습니다.
모터/보드의 외형 부피에 밀도를 곱해 실제 질량을 만들어내지 않습니다.

질량·관성 입력은 실제 시험 구성과 맞춥니다. 예를 들어 bare hull의 공력부터
모델링하더라도, 실제 부착된 부품의 질량을 자동으로 삭제하지 않습니다.
배터리와 계류 구성은 별도 입력 세트이며, 계류선의 힘도 별도 모델입니다.

## 4. 계산 기준

모든 계산은 m·kg·s 단위로 합니다. 길이 L/W/H는 **전체 지름**입니다.
기낭을 실제 팽창 형상에 가까운 타원체로 근사하면:

```text
V = π × L × W × H / 6
m_gas = P_abs × V × M_mix / (R_gas × T_K)
M_mix = χ × M_He + (1 − χ) × M_air
m_total = m_dry + m_gas
r_CV→CG = Σ(m_i × r_CV→i) / m_total       # 가스를 포함한 모든 질량
```

혼합식은 헬륨 외 성분이 건조공기라는 가정입니다. 내부 **절대압**, 절대온도,
순도와 부피를 사용합니다. 부력을 뺀 값은 관성 계산용 질량이 아닙니다.
기낭이 균일하고 기체가 균일하게 분포하면 둘의 CG를 CV로 둘 수 있습니다.
팽창한 기낭을 저울로 당겨 잰 값에는 부력이 작용하므로 전체 질량으로 사용하지 않습니다.
곤돌라 전체를 하나의 질량으로 넣었다면 그 내부 부품을 다시 합산하지 않습니다.
[NASA 상태식](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/equation-of-state/),
[혼합기체 몰질량 §3.1.6](https://www.nasa.gov/wp-content/uploads/2024/04/gfssp-v6-usermanual.pdf).

기낭은 균일한 얇은 필름의 타원체 표면으로 근사하고, 부품은 필요에 따라
점질량으로 둡니다. 각 질량의 CG에서 전체 CG까지 `d`라 할 때:

```text
Ixx += Ixx_component + m × (dy² + dz²)
Iyy += Iyy_component + m × (dx² + dz²)
Izz += Izz_component + m × (dx² + dy²)
```

부품 자체 관성을 생략할 때만 `I_component=0`으로 둡니다.
기낭 표면의 면적가중 질량분포로 관성을 구하고, 전체 텐서를 기체 좌표로 회전·이동한
다음 대각값을 취합니다. 임의의 타원체에 구형 껍질의 단순식을 적용하지 않습니다.
일반적인 균일 면밀도 타원체에 `m/3 × (b²+c²)`를 정확식처럼 쓰지 않습니다.
[MIT 관성텐서·평행축 정리](https://ocw.mit.edu/courses/16-07-dynamics-fall-2009/resources/mit16_07f09_lec26/).

내부 기체의 관성을 생략할 범위도 명시해야 합니다.
가스를 CV의 점질량으로 놓으면 자체 분포 관성은 생략하되 전체 CG까지의 평행축 항은
남습니다. 가스의 모든 관성 기여를 생략하는 근사와는 다릅니다.
파라미터 파일에서는 이 선택을 미확정으로 남겼습니다.

실제 추력곡선, 공력계수, 주변 공기에 의한 부가질량·부가관성은 이번 기하 자료의
계산 범위 밖입니다. 이것들은 기체 자체 질량·관성과 구분해 식별합니다.

## 5. 갱신·검증

```sh
python3 tools/simulation/export_parameters.py
```

현재 소스·CAD·검증 결과가 일치할 때만 `build/simulation_parameters.json`을 생성합니다.
CAD를 다시 만들거나 저장하지 않습니다. 레일 배치·광학센서 위치·센서 모델 변경은
기존 CAD 검증 절차를 거친 뒤 재추출합니다. 도구는 변경된 축 방향·기준점·비중립
자세를 거부합니다. 추진기 기준점은 저장된 축 위치로부터 계산하므로,
레일 위치·클램프 좌면 이동을 누락하지 않습니다. 계산 편의를 위한 별도 근사 좌표는
생성하지 않습니다.

이 자료의 추출·회전축/추력 작용선·미확정값·파일 일치 검사는
`tools/simulation/test_parameters.py`에서 수행합니다.
제작 도면과 조립 간섭 확인에는 항상 CAD 정확값을 사용합니다.
