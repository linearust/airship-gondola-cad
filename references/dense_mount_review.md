# Mounting interface source map

Plate geometry and permitted patterns are defined in
[mounting_plate.py](../gondola/parts/mounting_plate.py) and
[mounting_slots.py](../gondola/parts/mounting_slots.py); carrier support and
adhesive allocations are in [equipment_mounts.py](../gondola/parts/equipment_mounts.py).
Use the contracts and their checks when changing an occupied mount. This project
array is not a universal industry standard or a drop-in X500 interface.
